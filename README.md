# Dasom Senior Autobiography (다솜 시니어 자서전)

## 프로젝트 개요
**Dasom Senior Autobiography**는 시니어 사용자가 로봇(또는 태블릿)과 음성으로 상호작용하며 자신의 삶에 대한 자서전을 작성할 수 있도록 돕는 안드로이드 애플리케이션입니다. 사용자는 각 생애 주기별 질문을 듣고, 음성으로 답변을 녹음하여 자신만의 회고록을 만들어갈 수 있습니다.

## 주요 기능 (Overall Features)

### 1. 생애 주기별 카테고리 메뉴 (`MenuFragment`)
- **다양한 주제 제공**: 초기 정보(init), 부모님(parents), 어린 시절(childhood), 학창 시절(school), 청년기(youthhood) 등 생애 주기에 따른 카테고리를 제공합니다.
- **직관적인 UI**: 시니어 사용자가 쉽게 접근할 수 있도록 큰 글씨와 그리드 뷰 형태의 UI를 지원합니다.

### 2. 질문 목록 제공 (`QuestionListFragment`)
- 선택한 카테고리에 해당하는 세부 질문(Question) 리스트를 제공합니다.
- 사용자가 답변할 질문을 탐색하고 선택할 수 있습니다.

### 3. 음성 기반 인터랙션 및 답변 녹음 (`SpeechFragment`)
- **자동 음성 재생 (TTS)**: 화면에 진입하면 질문을 자동으로 읽어주는 TTS(Text-To-Speech) 기능을 제공합니다.
- **시각적 보조**: 질문에 맞는 배경 이미지를 제공하여 시니어의 기억 회상을 돕습니다.
- **음성 녹음 지원**: "답변 시작", "답변 종료", "다시 답변하기" 버튼을 통해 손쉽게 음성으로 답변을 남길 수 있습니다.
- **타이머 기능**: 답변 시간을 시각적으로 안내하며(예: 1분 제한 타이머 등), 녹음 진행 상태를 직관적으로 보여줍니다.

### 4. 답변 확인 및 추가 관리 (`QuestionDetailFragment`)
- **답변 및 질문 다시 듣기**: 녹음한 본인의 음성 답변과 질문을 다시 들을 수 있습니다.
- **추가 답변 기능**: 한 질문에 대해 최대 3개의 추가 답변을 녹음할 수 있어 더 풍부한 이야기를 남길 수 있습니다.
- **답변 삭제 및 수정**: 마음에 들지 않는 답변은 삭제하고 다시 녹음할 수 있는 관리 기능을 제공합니다.

### 5. 다국어 지원 및 반응형 UI
- 한국어, 영어(`en-US`), 스페인어(`es`) 등 다국어 설정에 맞춰 UI의 글꼴 크기 및 문구가 자동으로 최적화됩니다.

### 6. 로봇 시스템 및 서비스 연동
- **로봇 서비스 통합**: `com.onethefull.wonderfulrobotmodule`과 연동되어 로봇 및 기기 환경에 맞춘 음성 대화 멘트와 상호작용(로봇 모션 등)을 수행합니다. 
- **실행 모드별 기능 차이 (`ACTION_OPEN`, `ACTION_COMMAND`, `ACTION_SMARTFRIEND`)**:
  - `ACTION_OPEN`: 일반적인 앱 실행(터치 등) 모드입니다. 내부적으로는 기본 음성 인터랙션 지원을 위해 `ACTION_COMMAND`와 동일한 플로우로 매핑되어, 사용자가 앱을 켰을 때 기본적인 음성 안내를 받을 수 있도록 처리됩니다.
  - `ACTION_COMMAND`: 사용자의 직접적인 음성 명령(예: "자서전 시작해줘")을 통해 앱이 실행되는 모드입니다. 명령어 실행 상황에 특화된 음성 안내 멘트와 상호작용 시나리오가 제공됩니다.
  - `ACTION_SMARTFRIEND`: 로봇이 먼저 말을 거는 '스마트 친구' 기능을 통해 능동적으로 사용자에게 다가가 앱이 실행되는 모드입니다. 사용자에게 친근하게 대화를 유도하는 등 능동적 상황에 맞는 특화된 시나리오로 동작합니다.

## 시스템 아키텍처 및 환경
- **언어**: Kotlin
- **아키텍처**: MVVM (ViewModel, LiveData, Navigation Component 활용)
- **주요 기술**: Glide (이미지 로딩), RxBus (이벤트 처리), GCTextToSpeech (음성 합성), 음성 인식(STT) 및 녹음
